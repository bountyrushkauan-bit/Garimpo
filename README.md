# 🔥 Garimpeiro PCW

O Garimpeiro PCW é um agregador de ofertas de hardware para PC.

A ideia é encontrar preços realmente bons de componentes como:

- SSD
- GPU
- CPU
- RAM
- Monitor
- Fonte
- Cooler
- Gabinete

## 🚀 Tecnologias

- Python 3.12
- FastAPI
- SQLAlchemy
- SQLite no desenvolvimento
- HTML
- CSS
- JavaScript
- Render
